# Sincro280r — NC Generator

Gerador de arquivos NC Studio ATC Arcs (mm) para CNC Router Sincro280r construído em Electron.

## Funcionalidades

- **Configuração e Edição de Peças**: Canais, furos, rasgos e rebaixos.
- **Gerenciador de Ferramentas**: Cadastro de fresas, brocas e ferramentas com suporte a 3D.
- **Nesting**: Otimização de corte e posicionamento de peças em chapas.
- **Visualizador NC**: Simulação e inspeção do código G gerado.
- **Sistema de Licenciamento**: Gestão de licenças e chave por máquina.

## Instalação e Execução

```bash
# Instalar dependências
npm install

# Iniciar em modo de desenvolvimento
npm start

# Gerar instaladores e executáveis
npm run build
```
